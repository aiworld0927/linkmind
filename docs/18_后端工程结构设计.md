## 二、目录结构

```
backend/
  app/
    main.py                    # FastAPI 实例、CORS、路由注册、全局异常处理、lifespan（engine 建连/断开）
    core/
      config.py                # Settings(pydantic-settings)：DATABASE_URL、SECRET_KEY、CORS_ORIGINS、KNOWLEDGE_ROOT、ALLOW_ANONYMOUS、JWT_EXPIRE_MINUTES
      security.py              # JWT 编解码、OAuth2PasswordBearer、get_current_user 依赖（ALLOW_ANONYMOUS=true 时返回匿名用户）
      exceptions.py            # AppException(msg, code) + register_exception_handlers：RequestValidationError→422、HTTPException 透传、AppException→对应状态码、兜底 500
      constants.py             # ErrorCode(Enum)：OK=200/BAD_REQUEST=400/NOT_FOUND=404/VALIDATION_ERROR=422/INTERNAL_ERROR=500 + git/fs/mindmap 业务错误码
      deps.py                  # get_db(yield AsyncSession)、分页依赖(page≥1, page_size 1~100 默认 20)、get_current_user
      logging.py               # logging 统一配置
      pagination.py            # Page[T] 泛型 {total:int, items:list[T]}
      response.py              # ApiResponse[T] = {code, msg, data} 与 ok() 包装
    db/
      base.py                  # DeclarativeBase + naming_convention + TimestampMixin(created_at/updated_at timestamptz) + uuid 主键默认（uuid4）
      session.py               # create_async_engine(asyncpg) + async_sessionmaker(expire_on_commit=False)
      seed.py                  # 可选种子脚本（仅 maps 为空时插入）
    api/v1/
      router.py                # 汇总 include_router，prefix=/api/v1
      git/                     # A 模块 12 端点：/git/repos 系列
        {router,schemas,service,repository,models}.py
      fs/                      # B-1 /fs/dirs、B-2 /fs/tree、F-3 /docs/content（同文件系统域；无 ORM，KNOWLEDGE_ROOT 约束与路径遍历拦截在 service）
        {router,schemas,service}.py
      mindmap/                 # C+D+E+F 聚合域（同一聚合根：地图树）
        models.py              # MapModel/NodeModel/PropModel
        repository.py          # 全部数据访问
        service/{common,maps,nodes,props,notes}.py  # 业务逻辑
        schemas/{maps,nodes,props,notes}.py
        routers/{maps,nodes,props,notes}.py
  alembic/
    env.py                     # async 模式；versions/ 迁移
  tests/                       # pytest + pytest-asyncio + httpx.AsyncClient（按模块）
  .env.example                 # DATABASE_URL/SECRET_KEY/CORS_ORIGINS/KNOWLEDGE_ROOT/ALLOW_ANONYMOUS/JWT_EXPIRE_MINUTES
  pyproject.toml  README.md
```

**分层调用链**：router（校验/依赖/response_model）→ service（业务规则，全 async）→ repository（AsyncSession + SQLAlchemy 2.0 select/insert）→ models（Mapped[] 注解）。schemas 用 `ConfigDict(from_attributes=True)` 与 ORM 解耦。

**响应包装**：`ApiResponse[T] = {code:int, msg:str, data:T|None}`，router 统一包装返回；异常路径返回 `{code, msg, data: None}`。

## 四、数据库表设计（PostgreSQL 17）

当前实际共 **5 张业务表**，完整字段、约束与迁移说明见 [19_数据库设计.md](./19_数据库设计.md)；空库初始化脚本为 [backend/migrations/001_init.sql](../backend/migrations/001_init.sql)，Alembic 基线为 `backend/alembic/versions/0001_baseline.py`。

- `git_repos`：id uuid PK、name varchar(120) unique、fs_path varchar(1024) unique（相对 KNOWLEDGE_ROOT）、remote_url varchar nullable、timestamptz 时间戳
- `git_actions`：id uuid PK、repo_id FK→git_repos（CASCADE）、ts timestamptz、action varchar(40)、message text、files jsonb、ok boolean
- `maps`：id uuid PK、title varchar(30) unique、desc varchar(80)、repo_id FK→git_repos nullable（SET NULL）、timestamptz
- `nodes`：id uuid PK、map_id FK→maps（CASCADE）、parent_id self-FK nullable（CASCADE，null=一级）、name varchar(30)、sort_order int、timestamptz；同级不重名由 `ux_nodes_root_name`/`ux_nodes_child_name` 部分唯一索引保证
- `props`：id uuid PK、map_id FK→maps（CASCADE）、node_id FK→nodes nullable（CASCADE，null=地图级，对应前端 ROOT）、label varchar(30)、note_content text、note_tags jsonb、note_remark varchar(60)、doc boolean、doc_path varchar nullable、timestamptz
- git 运行时状态（branch/ahead/behind/merging/files/conflicts）实时计算不落库；Alembic 基线迁移一份覆盖全部 5 表

> 历史设计中的 10 张表（`knowledge_repository`、`knowledge_map`、`map_node`、`node_property`、`document`、`node_document_link`、`node_link`、`operation_audit`、`git_action`、`document_embedding`）**未落地**，当前迁移与 ORM 不包含，不能作为现状引用。
