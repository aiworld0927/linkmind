### Git 模块

#### Q1. Git 历史接口冗余（内嵌 vs 独立查询）

- **涉及接口**：GET `/git/repos/{repo_id}/log`、GET `/git/repos/{repo_id}/actions`
- **问题描述**：前端 API 层已封装（含 `limit` 参数）但无任何调用点；提交历史与动作记录实际随 `GitRepo.log/actions` 内嵌返回。二者语义重复：是否保留独立分页查询接口（用于历史面板分页加载），还是随仓库详情返回即可？
- **相关代码位置**：[git/api.ts L111-121](file:///coding/linkmind/frontend/src/features/git/api.ts#L111-L121)；[HistoryPanels.tsx L13-51](file:///coding/linkmind/frontend/src/features/git/components/HistoryPanels.tsx#L13-L51)
- **初步建议**：保留独立接口用于分页加载历史数据，`GitRepo` 内嵌字段仅返回最近 N 条作为摘要
- **状态**：待确认

- **涉及接口**：GET `/fs/tree`
- **问题描述**：`FsTreeNodeProp.content` 返回的是 md 文档全文还是摘要？前端把它直接放入笔记正文并按 ≤500 字的属性弹窗校验设计；若文档很长，截断规则、以及点击「查看笔记」时应拉全文（F-3）还是用返回内容，前后端需对齐。

- **状态**：待确认

#### Q3. fs/dirs 的 path 参数口径与越权拦截

- **涉及接口**：GET `/fs/dirs`
- **问题描述**：登记仓库时传空串表示"知识库根目录"，导入时传 `repo.fs_path`。空串/缺省/绝对路径/`..` 越权路径的行为约定，以及 `FsDirListing.path` 返回的是相对路径还是绝对路径，需统一。
- **相关代码位置**：[RepoDialog.tsx L24-46](file:///coding/linkmind/frontend/src/features/git/components/RepoDialog.tsx#L24-L46)；[Modals.tsx L430-456](file:///coding/linkmind/frontend/src/features/mindmap/Modals.tsx#L430-L456)
- **初步建议**：约定 path 一律为相对 KNOWLEDGE_ROOT 的路径，空串=根目录；后端统一做规范化 + 路径遍历拦截，返回值同样为相对路径
- **状态**：待确认
- **答复**：（待结合具体功能场景给出）

#### Q4. fs/dirs 与 fs/tree 的 path 口径一致性

- **涉及接口**：GET `/fs/tree`、GET `/fs/dirs`
- **问题描述**：导入时 `fetchFsTree(listing.path)` 直接复用 `fs/dirs` 返回的 `path` 字段。两个接口的 path 必须同口径（同样的根目录基准、同样的编码方式），否则下钻后导入会扫错目录。
- **相关代码位置**：[Modals.tsx L469](file:///coding/linkmind/frontend/src/features/mindmap/Modals.tsx#L469)；[Modals.tsx L444-456](file:///coding/linkmind/frontend/src/features/mindmap/Modals.tsx#L444-L456)
- **初步建议**：两个接口共用同一套路径解析/校验函数，联调时以下钻三层的目录做回归验证
- **状态**：待确认

#### Q13. 笔记全文经 URL query 传递的长度与安全风险

- **涉及接口**：F-1 读取笔记内容
- **问题描述**：「查看笔记」把**整篇 Markdown 全文 encodeURIComponent 后放进 URL query**：长文档受浏览器 URL 长度限制（超长会静默截断/打开失败），且刷新、分享链接都会携带全文。应改为按 id 拉取，URL 只传定位参数。
- **相关代码位置**：[SideDrawer.tsx L78-96](file:///coding/linkmind/frontend/src/features/mindmap/SideDrawer.tsx#L78-L96)；[NotePage.tsx L55](file:///coding/linkmind/frontend/src/pages/NotePage.tsx#L55)
- **初步建议**：URL 仅携带 `mapId/nodeId/propId/mode`，笔记页挂载时调 F-1 拉取内容
- **状态**：待确认
