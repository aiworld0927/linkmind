> **文档状态说明（2026-11-27）**
>
> 本文档第四章（4.1～4.8）为早期设计的**历史用例（未实现）**，其中“知识节点 / 依赖关系 / 循环依赖检测 / localStorage 恢复”等场景与当前产品（知识地图 / 节点 / 属性 / 笔记，PostgreSQL 持久化）不一致，未纳入自动化测试，仅保留供参考。

> 当前测试入口与判定标准请以第五章“当前测试入口”及 [15_API接口列表.md](./15_API接口列表.md)、[接口测试文档.md](./接口测试文档.md)、[前后端联调报告.md](./前后端联调报告.md) 为准。现状基线：后端 `pytest` 21/21、接口脚本 `scripts/api-test.sh` 197/197、前端 `vitest` 23/23 且 `tsc`/`build` 通过。

## 一、测试概述

本文档提供 LinkMind 知识图谱系统的测试指南，包括测试策略、测试用例、测试流程等内容。

## 二、测试环境

### 2.1 硬件要求

| 项目 | 要求 |
|------|------|
| CPU | 多核处理器，4核及以上 |
| 内存 | 8GB 及以上 |
| 磁盘 | 50GB 可用空间 |

### 2.2 软件环境

| 软件 | 版本 |
|------|------|
| Python | 3.12+ |
| Node.js | 20.x+ |
| Docker | 20.10+ |
| PostgreSQL | 17（主库，必需） |
| Neo4j | 5.26.0（可选组件，仅健康检查） |

### 2.3 测试工具

| 工具 | 用途 |
|------|------|
| pytest | Python 后端单元测试（`backend/tests`） |
| Vitest | 前端单元测试（`npm test`） |
| tsc / Vite | 前端类型检查与生产构建 |
| scripts/api-test.sh | 后端接口联调脚本（curl + 断言） |
| Postman / curl | 接口手工调试 |

> 早期设想的 Jest、Cypress 未在当前工程落地，不再作为测试入口。

## 三、测试策略

### 3.1 测试类型

| 测试类型 | 说明 | 覆盖范围 |
|----------|------|----------|
| 单元测试 | 测试单个函数或组件 | 后端 API、前端组件 |
| 集成测试 | 测试多个模块协作 | API 调用链、组件交互 |
| 端到端测试 | 模拟真实用户操作 | 完整业务流程 |
| 性能测试 | 测试系统性能指标 | 响应时间、并发能力 |
| 安全测试 | 测试系统安全性 | 输入验证、权限控制 |

### 3.2 测试级别

| 级别 | 说明 | 执行时机 |
|------|------|----------|
| L0 - 单元测试 | 代码提交时自动执行 | CI 流水线 |
| L1 - 集成测试 | 合并到主分支前执行 | PR 审核 |
| L2 - 端到端测试 | 发布前执行 | 发布流程 |
| L3 - 性能测试 | 重大版本发布前执行 | 版本发布 |
